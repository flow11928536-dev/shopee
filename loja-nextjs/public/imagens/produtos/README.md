# 📸 Fotos dos Produtos

Coloque AQUI todas as fotos dos móveis e eletrodomésticos.

- Formato recomendado: **.webp** (melhor performance / Core Web Vitals)
- Nome do arquivo deve bater com o campo `imageFile` em `src/data/products.ts`

Exemplo:

```
public/imagens/produtos/cozinha-compacta-madesa-glamy.webp
```

E em `src/data/products.ts`:

```ts
// INSERIR_AQUI_O_CAMINHO_DA_IMAGEM_EM_IMAGENS_PRODUTOS
imageFile: "/imagens/produtos/cozinha-compacta-madesa-glamy.webp",
```
